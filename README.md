# Innova4

Site institucional estático, publicado via GitHub Pages.

- `index.html` — página única (Sobre, Marcas, Contato, Privacidade).
- `styles.css` — estilo, sem dependência externa.
- `.nojekyll` — desliga o processamento Jekyll do GitHub Pages.

Sem backend, sem formulário, sem analytics. Publicar: Settings → Pages →
Source → `main` / `(root)`.
